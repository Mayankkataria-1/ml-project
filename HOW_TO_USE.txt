# Model comparison and graph templates

These are templates only. They do not contain measured results from your ML project.

1. Open `model_comparison_TEMPLATE.csv`.
2. Enter the real held-out test MAE, RMSE and R2 for each model.
3. Install dependencies: `python -m pip install pandas matplotlib`.
4. Run: `python generate_comparison_graphs.py`.

The script creates PNG bar charts for metrics that have real numeric values.
Do not submit empty charts or invented metrics as project findings.
